# DSH 插件：侧边栏 Tab 批量关闭

给 DeepSeek Harness **右侧边栏的 tab** 增加右键菜单项：关闭左侧、关闭右侧、关闭其他、关闭全部。

## 功能

在右侧边栏任意 tab 上**右键**，菜单里会出现：

- **关闭左侧**：关闭当前 tab 左边的全部 tab
- **关闭右侧**：关闭当前 tab 右边的全部 tab
- **关闭其他**：关闭除当前 tab 外的全部 tab
- **关闭全部**：关闭当前这一栏的全部 tab，但**保留「开始」页**，侧边栏不会收起

说明：

- 只作用于**当前这一栏（pane）**；右侧分成两栏时，互不影响。
- 顺序按 tab 栏里**从左到右**的视觉顺序。
- 系统规定「唯一停靠的 guide tab」不能关闭，插件会**自动跳过**，不会报错。
- **关闭全部**会跳过「开始」（guide）页；即使它此前被关掉了，也会自动补回来，所以点完仍停留在开始页，不会把整个侧边栏关掉。
- 当前没有可关闭的项时，对应菜单项会**变灰**。

## 安装（本地开发）

1. 打开左侧 **插件** 页面 → **添加插件**
2. 填入本插件**目录的绝对路径**：`/Users/lwf/Documents/ideaProjects/dsh-plugins/dsh-sidebar-tab-close`
3. 安装后点 **立即启用**，然后**完全退出并重新打开** DeepSeek Harness

## 实现说明（给维护者）

- 纯前端插件：`index.js` 宿主端为空，逻辑全在 `client.js`。
- 通过官方扩展位 `sidebar.right.tab.menu.item` 注册菜单项，不改动任何官方源码。
- 关闭动作调用 `ctx.sidebarRight.close(tabId)`；这是右侧边栏插件公开的导航控制器。
- 「关闭全部」先按 `kind === 'guide'` 跳过「开始」页，再调用 `ctx.sidebarRight.openTab('guide')` 兜底补回（该调用本身也会把侧边栏展开），因此侧边栏不会被收起。
